## 1. 项目概述

### 1.1 目标

打造一个 **轻量、美观、跨平台** 的 ASMR 音声作品管理器,聚焦音声作品的**发现 → 入库 → 下载 → 播放 → 翻译**全链路,同时兼容同人游戏、漫画等作品类型。

本项目采用 **B/S 架构**:服务端 Rust 常驻,前端 Vue 3 在浏览器中运行,因此:

- 无需为每个平台打包客户端,浏览器即客户端;
- 服务端可部署在 NAS / 服务器上,局域网内任意设备访问;
- 目录浏览、打开文件夹、数据库备份等操作通过**服务端代理实现**(如服务端目录浏览器、`VACUUM INTO` 导出)。

### 1.2 核心能力一览

| 能力 | 说明 |
|:----|:------|
| 🗂️ **作品库管理** | 网格/横版/列表三视图、FTS5 全文搜索、状态/标签/分组筛选、多字段排序、批量删除 |
| ➕ **智能导入** | RJ 号导入(优先 DLsite,受阻自动回退 asmr.one)、本地文件夹递归扫描识别 RJ、智能分组 |
| 📄 **作品详情** | 多语言标题、元数据、声优、标签编辑、音轨列表、横版封面、LLM 翻译入口 |
| 🏆 **DLsite 榜单** | 日/周/月/年度/累计五周期音声榜 Top 100,每 4 小时自动抓取,一键入库 |
| 🌐 **ASMR ONE 在线** | 热门/推荐/全部浏览、收藏/播放列表/历史、在线详情、在线试听、文件树下载 |
| ⬇️ **下载引擎** | HTTP Range 断点续传、SSE 实时进度、暂停/继续/取消、自动解压与音轨扫描、asmr.one 多文件勾选下载 |
| 🎵 **音频播放器** | 播放/暂停/切歌、拖动 Seek、0.5x~2.0x 倍速、循环模式、进度持久化、常驻迷你栏 |
| 💬 **字幕系统** | `.vtt`/`.srt`/`.lrc` 解析、在线自动匹配中文字幕、浏览器悬浮歌词窗口 |
|  **LLM 翻译** | 日文标题+简介 → 简体中文,OpenAI 兼容接口,批量/单作品/入库自动翻译,限速+并发+重试 |
| 🎨 **三套主题** | 深色 Midnight Obsidian / 浅色 Clean Slate / 樱花粉 Sakura Pink,实时切换 |
| 💾 **数据迁移** | 便携 SQLite,WAL 模式,一键导出/还原备份 |

### 1.3 目标用户

- 持有大量 DLsite 音声作品、需要统一管理的老用户;
- 有本地文件归档习惯(NAS / 移动硬盘),需要按 RJ 号建立索引;
- 有一定动手能力,能自行运行 Rust + Node 环境。

### 3.4 并发模型

- 全局单连接 `Mutex<rusqlite::Connection>`,所有阻塞式 DB 操作放入 `tokio::task::spawn_blocking`,**不在 async 上下文直接持锁**。
- SQLite 开启 WAL + `synchronous=NORMAL`,兼顾并发读与写入性能。
- 下载任务使用独立 `std::thread`,并通过独立连接打开数据库写回状态。
- 定时任务:榜单刷新(4 小时间隔)、翻译调度器(1 秒 tick),均在 `main` 中 `tokio::spawn`。
- 前端进度通过 `broadcast::channel(256)` + SSE 推送,无订阅者时静默丢弃。

## 4. 数据库设计

### 4.1 表结构(实际实现)

#### works — 作品主表

```sql
CREATE TABLE IF NOT EXISTS works (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    rj_code         TEXT    NOT NULL UNIQUE,          -- RJ 号(唯一)
    title_ja        TEXT,                             -- 日文标题
    title_zh        TEXT,                             -- 中文标题(LLM 翻译写入)
    title_en        TEXT,                             -- 英文标题
    circle_name     TEXT,                             -- 社团名
    circle_id       TEXT,                             -- 社团 ID
    cover_url       TEXT,                             -- 封面 URL
    work_type       TEXT    NOT NULL DEFAULT 'voice', -- voice/game/comic/cg
    price           INTEGER,                          -- 价格(日元)
    sale_date       TEXT,                             -- 发售日期 YYYY-MM-DD
    description     TEXT,                             -- 原始简介(日文)
    age_class       TEXT,                             -- general/r18/r18g
    duration_min    INTEGER,                          -- 总时长(分钟)
    file_size_mb    REAL,                             -- 文件大小(MB)
    dlsite_url      TEXT,                             -- DLsite 页面链接
    description_zh  TEXT,                             -- 中文简介(LLM 翻译写入)
    created_at      TEXT    DEFAULT (datetime('now')),
    updated_at      TEXT    DEFAULT (datetime('now'))
);
```

> **关键约束**:`upsert_work` 在冲突(RJ 已存在)时对 `title_zh` 使用 `COALESCE(excluded.title_zh, works.title_zh)`,**避免重新入库清空已有翻译**;`description_zh` 不在冲突更新列中,始终保留译文。

#### 关联与附属表

```sql
-- 声优
CREATE TABLE IF NOT EXISTS voice_actors (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL UNIQUE,
    dlsite_url TEXT
);
CREATE TABLE IF NOT EXISTS work_actors (
    work_id  INTEGER NOT NULL,
    actor_id INTEGER NOT NULL,
    PRIMARY KEY (work_id, actor_id),
    FOREIGN KEY (work_id)  REFERENCES works(id)        ON DELETE CASCADE,
    FOREIGN KEY (actor_id) REFERENCES voice_actors(id) ON DELETE CASCADE
);

-- 标签
CREATE TABLE IF NOT EXISTS tags (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL UNIQUE,
    color TEXT DEFAULT '#888888',
    is_preset INTEGER DEFAULT 0
);
CREATE TABLE IF NOT EXISTS work_tags (
    work_id INTEGER NOT NULL,
    tag_id  INTEGER NOT NULL,
    is_auto INTEGER DEFAULT 0,      -- 是否由抓取自动生成
    PRIMARY KEY (work_id, tag_id),
    FOREIGN KEY (work_id) REFERENCES works(id) ON DELETE CASCADE,
    FOREIGN KEY (tag_id)  REFERENCES tags(id)  ON DELETE CASCADE
);

-- 分组(一个作品只属于一个分组)
CREATE TABLE IF NOT EXISTS groups (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name  TEXT NOT NULL UNIQUE,
    color TEXT DEFAULT '#597ef7'
);
CREATE TABLE IF NOT EXISTS work_groups (
    work_id  INTEGER PRIMARY KEY,
    group_id INTEGER NOT NULL,
    FOREIGN KEY (work_id)  REFERENCES works(id)  ON DELETE CASCADE,
    FOREIGN KEY (group_id) REFERENCES groups(id) ON DELETE CASCADE
);

-- 本地文件
CREATE TABLE IF NOT EXISTS local_files (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    work_id INTEGER NOT NULL,
    local_path TEXT NOT NULL,
    file_type TEXT DEFAULT 'archive',            -- archive/dir/unknown
    download_status TEXT DEFAULT 'not_downloaded',
    download_progress REAL DEFAULT 0,
    file_size INTEGER,
    created_at TEXT DEFAULT (datetime('now')),
    FOREIGN KEY (work_id) REFERENCES works(id) ON DELETE CASCADE,
    UNIQUE (work_id, local_path)
);

-- 音轨
CREATE TABLE IF NOT EXISTS audio_tracks (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    work_id INTEGER NOT NULL,
    file_path TEXT NOT NULL,
    track_number INTEGER,
    title TEXT,
    duration_sec REAL,
    file_format TEXT,          -- mp3/wav/flac/m4a/ogg/aac
    file_size INTEGER,
    FOREIGN KEY (work_id) REFERENCES works(id) ON DELETE CASCADE
);

-- 播放记录
CREATE TABLE IF NOT EXISTS play_history (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    work_id INTEGER NOT NULL,
    track_id INTEGER,
    last_position REAL DEFAULT 0,
    play_count INTEGER DEFAULT 0,
    last_played_at TEXT,
    FOREIGN KEY (work_id)  REFERENCES works(id)       ON DELETE CASCADE,
    FOREIGN KEY (track_id) REFERENCES audio_tracks(id) ON DELETE SET NULL
);

-- 设置(key-value)
CREATE TABLE IF NOT EXISTS settings (
    key   TEXT PRIMARY KEY,
    value TEXT
);
```

#### dlsite_rankings — 榜单快照

```sql
CREATE TABLE IF NOT EXISTS dlsite_rankings (
    term        TEXT    NOT NULL,       -- day/week/month/year/total
    position    INTEGER NOT NULL,       -- 榜单内序号(主键,保证唯一)
    rank        INTEGER NOT NULL,       -- DLsite 展示名次(可并列)
    rj_code     TEXT    NOT NULL,
    title       TEXT,
    circle_name TEXT,
    cover_url   TEXT,
    price       INTEGER,
    sale_date   TEXT,
    dl_count    INTEGER,
    rating      REAL,
    tags_json   TEXT,
    fetched_at  TEXT    NOT NULL DEFAULT (datetime('now')),
    PRIMARY KEY (term, position)
);
```

> ⚠️ **设计要点**:DLsite 榜单存在**并列名次**(如同一名次并列三部作品),若用 `(term, rank)` 作主键会冲突。因此以**抓取顺序 `position`** 作主键,`rank` 仅作展示。此为实际踩坑后的修正,并有回归测试覆盖。

#### translation_tasks — LLM 翻译任务

```sql
CREATE TABLE IF NOT EXISTS translation_tasks (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    work_id         INTEGER NOT NULL UNIQUE,   -- 每作品一任务(重试/重译复用)
    status          TEXT    NOT NULL DEFAULT 'pending', -- pending/processing/success/failed
    source_title    TEXT,
    translated_title TEXT,
    source_desc     TEXT,
    translated_desc TEXT,
    error           TEXT,
    retry_count     INTEGER NOT NULL DEFAULT 0,
    created_at      TEXT DEFAULT (datetime('now')),
    updated_at      TEXT DEFAULT (datetime('now')),
    FOREIGN KEY (work_id) REFERENCES works(id) ON DELETE CASCADE
);
```

#### works_fts — 全文索引

```sql
-- 使用独立 FTS5 表(不绑定 content='works'),
-- 避免外部内容表在删除/重建索引时出现 "database disk image is malformed"。
CREATE VIRTUAL TABLE IF NOT EXISTS works_fts USING fts5(
    rj_code, title_ja, title_zh, title_en, circle_name, description
);
```

启动时先 `DROP TABLE IF EXISTS works_fts` 再重建并从 `works` 全量回填,保证索引与主表一致。

#### 预留表(已建表,当前无 UI 入口)

`accounts` 与 `work_accounts` 为多账号同步场景预留,当前实现**不涉及 DLsite 账号登录**,导入以 RJ 号为单位进行。表结构已就绪,后续扩展无需迁移。

### 4.2 唯一索引与数据清洗

迁移脚本中会对历史脏数据做幂等清理,再建唯一索引:

```sql
-- local_files:同一作品同一路径只保留最小 id
DELETE FROM local_files WHERE id NOT IN (
    SELECT MIN(id) FROM local_files GROUP BY work_id, local_path);
CREATE UNIQUE INDEX IF NOT EXISTS idx_local_files_work_path
    ON local_files(work_id, local_path);

-- play_history:save_play_progress 依赖 ON CONFLICT(work_id, track_id)
DELETE FROM play_history WHERE id NOT IN (
    SELECT MIN(id) FROM play_history GROUP BY work_id, track_id);
CREATE UNIQUE INDEX IF NOT EXISTS idx_play_history_work_track
    ON play_history(work_id, track_id);
```

> `track_id` 为 NULL 时 SQLite 视 NULL 互异,唯一索引不冲突,符合「一首歌多条无 track 记录」的预期。

### 4.3 索引清单

| 索引 | 目标 |
|:---|:---|
| `idx_works_rj` | RJ 号查询 |
| `idx_works_circle` | 社团筛选 |
| `idx_works_type` | 作品类型 |
| `idx_audio_work` | 音轨按作品 |
| `idx_local_files_work_path` | 本地文件唯一 |
| `idx_dlsite_rankings_rj` | 榜单按 RJ 关联本地作品 |
| `idx_play_history_work` / `idx_play_history_played` | 播放历史 |
| `idx_translation_tasks_status` | 翻译任务认领 |

## 5. 后端设计

### 5.1 启动流程

```
1. 解析数据库路径(resolve_db_path)
     ASMR_DB_DIR > exe 同级目录(便携模式) > 当前工作目录
2. init_database:打开连接 → WAL / foreign_keys / synchronous → migrate()
3. reset_processing_translations:上次运行遗留的 processing 任务重置为 pending(断点续跑)
4. 解析前端产物目录(resolve_dist_dir),缺失时提示但 API 仍可用
5. 构造 SharedState
6. spawn DLsite 榜单定时任务(启动即检查是否过期,之后每 4 小时)
7. 构造 Router(约 60 条路由)+ CorsLayer::permissive
8. spawn LLM 翻译调度器
9. 监听 ASMR_HOST:ASMR_PORT(默认 127.0.0.1:1421)
```

### 5.3 下载引擎

**直链下载(`/api/download`)**

```
1. 从 works 取 RJ 与标题,解析下载目录 + .staging 暂存目录
2. 若该 RJ 已有任务 → 拒绝
3. 注册 DownloadHandle{task, cancel: AtomicBool},返回 ok
4. 独立线程执行 run_download:
   - 以 .part 文件当前大小作为 Range 起点(断点续传)
   - 256KB 分块读取,每 ≥0.2s 广播一次进度与速率
   - 循环内检查 cancel 标志;读错误则 sleep 500ms 后重试(网络抖动容错)
   - 完成后 rename 到最终路径,登记 local_files
   - 若为 .zip → extract_zip 解压(sanitize 掉 `..` 与根路径,防目录穿越)
   - 扫描音频重建 audio_tracks
```

**asmr.one 多文件下载(`/api/download/asmr`)**

- 目标目录为 `{下载目录}/{RJ}/`,按文件树相对路径落盘;
- 已存在且非空的文件跳过,计入总体进度;
- 需要 Token 的域名(`asmr-100.com`/`asmr-200.com`)自动注入 Bearer;
- 每个文件单独计算进度,总体进度按累计字节比例,封顶 99%,完成时 100%;
- 完成后登记 `local_files` 并扫描音轨。

**队列控制语义**

| 操作 | 行为 |
|:---|:---|
| pause | 仅置任务状态为 `paused` 并广播(读取循环继续但 UI 显示暂停) |
| resume | 置回 `downloading` 并广播 |
| cancel | 置 `cancel` 原子标志 + 状态 `cancelled`,线程在下一个分块边界退出 |

### 5.4 SSE 进度推送

```rust
// state.rs
pub struct DownloadProgressEvent {
    pub rj_code: String, pub status: String, pub progress: f64,
    pub speed: f64, pub bytes_done: u64, pub bytes_total: u64,
    pub error: Option<String>,
}
```

`broadcast::channel(256)` → `/api/events` 以 `event: download-progress` 推送 camelCase JSON。前端用 `EventSource` 订阅,浏览器断线自动重连;`Lagged` 错误时跳过而非中断。

### 5.5 音频与文件流

**本地音频**(`/api/audio?path=`)实现单区间 Range:

- 支持 `bytes=a-b` / `bytes=a-` / `bytes=-suffix` 三种形式;
- 起点越界返回 `416` + `Content-Range: bytes */size`;
- `206` 响应带 `Content-Range` 与 `Accept-Ranges: bytes`;
- 通过 `ReaderStream::with_capacity(..., 128KB)` + `take()` 精确限量流式返回。

**asmr.one 文件代理**(`/api/asmr/file/{*hash}`):

- 从 DB 读取 Token、代理配置、API 基址,Token **不暴露给前端**;
- 先试完整 hash,404 时回退纯 fileId(兼容两种 hash 形态);
- 原样透传状态码与 `Content-Type/Length/Range/Accept-Ranges/Last-Modified/ETag`;
- 请求头 `Range` 透传,使浏览器 `<audio>` 可直接 seek。

> 在线试听优先使用 asmr.one 公开 CDN 的 `mediaStreamUrl`(无需 Token),仅当 CDN URL 缺失时才回退到本服务代理路径。

## 7. 网络代理设计

`api/proxy.rs` 提供**按目标站点分别开关**的出站代理:

```rust
pub enum ProxyTarget { Dlsite, AsmrOne, Llm }

pub struct ProxyConfig {
```

要点:

> 说明:`reqwest` 只读取环境变量形式的代理设置,不识别 macOS 系统代理。因此在 VPN 全局 TUN 模式下无需配置本项;当需要按站点分流时才使用此处的开关。

## 8. LLM 翻译子系统

### 8.1 配置(LlmConfig)

从 settings 读取并 clamp:

| 字段 | 默认 | 范围 |
|:---|:---|:---|
| endpoint / api_key / model | 空 | — |
| max_retry | 3 | 0-10 |
| rps | 2 | 1-100 |
| threads | 1 | 1-4 |
| auto_translate | false | — |
| prompt | 系统默认 | 可清空恢复默认 |

`ready()` 要求 endpoint、api_key、model 三者非空;**未就绪时调度器空转**,不认领任务。

`chat_url()` 归一化端点:末尾斜杠去除,已以 `/chat/completions` 结尾则直接使用,否则拼接。

### 8.2 翻译请求

```
POST {chat_url}
Authorization: Bearer {api_key}
{
  "model": "<配置>", "temperature": 0.3,
  "messages": [
    {"role": "system", "content": "<prompt>"},
    {"role": "user",   "content": "<待翻译文本>"}
  ]
}
```

响应取 `choices[0].message.content`,并去除首尾引号与 `「」`。超时 60 秒,走 LLM 代理开关。

**系统默认 Prompt**:

> 你是专业的 ASMR 音声作品翻译。将用户提供的日文作品标题和简介准确翻译成简体中文:保留人名、社团名、作品系列名等专有名词的惯用译法;语气自然流畅,符合中文表达习惯;不要添加解释、注释、罗马音或原文,只输出翻译后的中文文本。

### 8.3 调度器

`spawn_scheduler` 每秒 tick:

```
1. 读取 LlmConfig;未 ready 则跳过本轮
2. 统计 processing 任务数
3. free = threads - processing;free <= 0 则跳过
4. claim_pending_translations(free):
     UPDATE translation_tasks SET status='processing' ...
     WHERE id IN (SELECT id FROM translation_tasks
                  WHERE status='pending' ORDER BY id LIMIT ?)
     RETURNING id, work_id
5. 每个任务 tokio::spawn(process_task) 并发执行
```

**单任务流程**:

```
读取作品 → 取 title_ja(必翻)与 description(有则翻)
  ├ 先翻标题:最多 max_retry+1 次,每次先过全局限速门,失败间隔 2s 重试
  │   全失败 → fail_task("标题翻译失败: ...")
  ├ 再翻简介:同样重试策略
  │   全失败 → fail_task("简介翻译失败(标题已翻译): ...")
  └ 成功 → set_work_translation(title_zh, description_zh)
          并写回任务 translated_title/desc + status=success
```

**全局限速门**:静态 `Mutex<Option<Instant>>`,任意两次 LLM 请求间隔不少于 `1000/rps` 毫秒;不满足则 `sleep` 后重试获取。使用 `unwrap_or_else(|e| e.into_inner())` 容忍锁中毒。

**断点续跑**:启动时 `reset_processing_translations` 把遗留的 `processing` 重置为 `pending`,避免进程被杀导致任务永久卡住。

### 8.4 入库自动翻译

`import_by_rj` 尾部检查 `llm_auto` 开关,开启且有非空 `title_ja` 时调用 `enqueue_translation`,响应中返回 `autoTranslated` 供前端提示。

### 8.5 任务记录的幂等与语义

- `enqueue_translation` 以 `work_id` 唯一:已存在则重置为 `pending` 并清空错误(即**重译会覆盖已有译文**);
- `enqueue_missing_translations` 只挑**无 `title_zh` 且无 pending/processing 任务**的作品;
- 删除任务记录**只删记录**,不清除已写入的 `title_zh`/`description_zh`;
- 状态四档:排队中(灰)/ 进行中(蓝,带转圈)/ 成功(绿)/ 失败(红)。

### 9.2 全局布局(App.vue)

```
┌────────────────────────────────────────────────────┐
│ Sidebar │ TopBar(标题 + 播放状态 + 刷新 + 下载角标) │
│  (w-52) ├──────────────────────────────────────────┤
│         │                                          │
│         │   <router-view> + KeepAlive              │
│         │   (main.overflow-y-auto)                 │
│         │                                          │
│         ├──────────────────────────────────────────┤
│         │ MiniPlayer(常驻,高 4rem)                │
└────────────────────────────────────────────────────┘
```

- `route.name === 'player'`(全屏播放器)与 `desktop-subtitle`(弹窗)不套此布局;
- **KeepAlive include = `['AsmrOnlinePage', 'DlsitePage']`**,用于从详情页返回时保留 tab、数据与滚动位置;
- 键盘快捷键仅在 `playerStore.visible` 时生效:`Space` 播放/暂停、`←/→` ±5 秒、`↑/↓` 音量 ±0.05(输入框内不拦截);
- 挂载时:同步主题 → 加载标签/分组/作品 → 加载下载设置与队列 → 订阅 SSE → 订阅悬浮字幕关闭事件。

### 9.3 作品库(HomePage)

- **三视图**:`grid`(海报 3:4 裁切)、`cover`(横版完整封面不裁切)、`list`(表格);由 `WorkFilters` 切换;
- **列数联动**:`recalcColumns` 依据容器宽度计算横版列数 `floor((width+12)/(300+12))`,海报理想宽取相邻列更接近者,并用 CSS 变量 `--poster-img-h`(= 0.75 × 横版列宽)保证**海报卡片与横版卡片严格等高**;`ResizeObserver` 监听容器 + window resize 兜底;
- 筛选状态存于 `worksStore`,通过侧边栏点击标签/分组/状态时若不在首页会先 `router.push({name:'home'})` 再应用筛选;
- 分页 48/页;空态引导跳转导入页;
- 选择模式支持全选/批量删除(`POST /api/works/delete-batch`)。

### 9.4 本地作品详情(DetailPage)

- 布局:横版封面(`w-72 self-center`,不裁切)→ 右侧 RJ(一键复制)、下载状态角标、标题、元数据、声优、`TagEditor`;下方简介卡(优先 `description_zh`,带「中文翻译」标)→ `TrackList`;
- 操作:播放(读取进度定位音轨)、下载、扫描音轨、打开本地目录、关联本地文件夹、**LLM 翻译**、打开 DLsite/asmr.one、asmr.one 在线试听、asmr.one 文件树下载、删除;
- 弹窗:asmr 文件树、服务端目录选择器。

### 9.5 播放器(PlayerPage + MiniPlayer + player store)

- `player.playIndex(index, initialTime)` 创建 Howler 实例:
  - 在线音轨(`isOnlineTrack`)直接用其 URL(CDN 或 `/api/` 代理);
  - 本地音轨用 `/api/audio?path=`,服务端 Range 流;
  - `html5: true` 以支持 Range seek;
- **进度持久化**:`persistProgress` 每 500ms 定时器 + 暂停/停止/结束事件触发写入;**在线音轨不写进度**(避免与本地 track_id 混淆);
- **错误容错**:`onloaderror` 累加错误计数,达到播放列表长度则停止(防死循环),否则跳下一首;
- 循环模式 none/one/all;倍速 0.5~2.0;`prev` 在播放超过 3 秒时回到开头,否则切上一首;
- 迷你栏常驻底部(播放器页除外),含悬浮进度条、倍速、循环、音量、展开按钮。

### 9.6 字幕系统

- **解析**:`detectAndParse` 检测前 2048 字符 → `WEBVTT` 开头为 VTT;含 `[mm:ss]` 为 LRC;含 `-->` 优先 SRT 失败回退 VTT;
- **在线匹配**:从 `track.subtitles` 按优先级选择 —— 中文(正则 `/zh|chs|cht|cmn|chi|中|简|繁|译/`)→ 日文 → 英文 → 首个;
- **本地匹配**:`GET /api/subtitle/find?path=`,先同目录同名(`.lrc/.vtt/.srt`,大小写不敏感),再向上定位含 RJ 号的作品根目录递归搜索,按「同名 > 包含名 > 路径」排序取首个;
- **同步**:`subtitleText = getActiveCue(cues, currentTime)?.text ?? ""`,由 500ms 定时器驱动的 `currentTime` 计算;`getActiveCue` 二分查找;
- **竞态防护**:`subtitleReqSeq` 请求序号,只有最新请求能写入状态;
- **悬浮歌词窗口**:浏览器无法置顶/无边框,改用 `window.open` 弹窗(560×150,屏幕底部居中)+ `BroadcastChannel("dlsite-asmr-subtitle")` 同步文本,300ms 推送一次;主窗口监听关闭消息同步状态。

### 9.7 DLsite 榜单页与在线浏览页

**共同点**

- 均启用 KeepAlive;滚动位置通过**实时 scroll 监听**记录(仅当 `route.name` 为 `dlsite`/`asmr` 时写入),点击进详情前调用 `saveScrollNow()` 兜底;返回时 `onActivated` 中 `nextTick` + 50ms/200ms 两次 `setTimeout` 恢复(规避图片懒加载导致的高度不足)。
- 卡片统一设计:横版封面不裁切;已入库显示角标;未入库卡片右下角「入库」按钮,使用 `@click.stop.prevent` 阻止锚点默认跳转。

**DlsitePage**

- 周期 tabs(日/周/月/年/累计)+ 数量下拉(20/50/100,默认 20);
- 顶部显示最近抓取时间(SQLite UTC → 本地时间);
- 「刷新」按钮触发全量 5 周期抓取;
- 点击:已入库 → 本地详情 `/work/{id}`;未入库 → 在线预览 `/dlsite/work/{rj}`;
- 入库:调用 `importByRj` 后**原地更新 `work_id`** 并同步 worksStore(无需刷新页面)。

**AsmrOnlinePage**

- 来源 tabs:热门(`dl_count`)/ 推荐(`random`)/ 全部(可切 最新 `release`/下载量 `dl_count`/评分 `rating`);
- 账号 tabs:收藏(`/api/review`)/ 播放列表(概要以列表展示,点击下钻)/ 历史(本地播放记录);
- 分页 20/页,客户端上下页,翻页后 `window.scrollTo({top:0})`;
- 入库按钮同 DLsite,按 RJ 号导入并原地写 `local_work_id`。

**在线详情页(AsmrOnlineDetailPage)**

- 因路由参数变化会复用组件,使用 `computed workId` + `watch` 重新加载;
- 并行拉取音轨与文件树(文件树失败忽略);
- 构造 `fakeView: WorkView`(id=0,RJ 缺省 `ASMR-{id}`)供播放器与 TrackList 复用;
- `TrackList` 传 `online` 与 `tree`,显示「音频 N / 全部文件 N」切换。

### 9.8 TrackList 文件树交互

- 有 `tree` 时顶部出现「音频 N / 全部文件 N」切换;`watch(tree)` 重置为音频视图并清空展开集;
- 文件树**默认全部折叠**(`expanded: Set<string>`),点击文件夹展开/收起;
- 行 key 为 `${prefix}/${i}:${title}`,含 `depth/title/nodeType/extension/size/duration/isFolder/fileCount`,缩进 `16 + depth*18 px`;
- 「全部文件 N」与总大小使用**全树递归统计**,不受折叠状态影响;
- 图标按 `nodeType` 区分(audio/image/text/other),类型标签显示「图片/字幕文本/扩展名大写」。

### 9.9 翻译页(TranslatePage)

- 工具栏:「翻译全部未翻译作品」批量入队 + 刷新;
- 列表 10 条/页:状态徽标、原文标题 → 中文译文、RJ 号、简介字数、失败原因、更新时间;
- 成功记录可点击进入本地详情;
- 行操作:重试 / 删除;
- **有 pending/processing 任务时每 3 秒轮询**,无则停止。

### 9.10 设置页(SettingsPage)

六个分区,统一保存按钮:

1. **主题风格** — 三卡选择,即时 `applyTheme`;
2. **下载设置** — 下载目录(带服务端目录选择器)、并发数;
3. **asmr.one 数据源** — 地址/账号/密码 + 「保存并登录」(先存设置再 `asmr-login`,成功后回读刷新 Token)+ 手动 Token 保存/清除;
4. **网络代理** — 代理地址 + 三个开关(DLsite / ASMR ONE / LLM);
5. **LLM 翻译** — 端点/密钥/模型、最大重试、每秒请求上限、线程数、入库自动翻译开关、翻译 Prompt;
6. **数据库** — 显示路径、打开目录、导出备份、上传还原。

### 9.11 API 层约定

- 全部走相对路径 `/api/...`,开发时由 Vite proxy 转发到 `127.0.0.1:1421`;
- 统一 `request<T>`:网络异常包装为「无法连接服务器,请确认后端已启动」;非 2xx 优先取响应体 `error` 字段作为消息;
- 无响应体(204/空)返回 `undefined`;
- 下载进度通过 `EventSource("/api/events")` 订阅 `download-progress`,返回取消订阅函数。

## 10. 主题与样式体系

### 10.1 CSS 变量

三套主题定义在 `html[data-theme=...]` 下,值以 **RGB 空格分隔**形式书写以配合 Tailwind `<alpha-value>`:

| 变量 | dark(Midnight Obsidian) | light(Clean Slate) | sakura(Sakura Pink) |
|:---|:---|:---|:---|
| `--color-bg` | `18 18 30` | `246 248 252` | `255 245 248` |
| `--color-bg-deep` | `13 13 22` | `238 242 248` | `255 233 241` |
| `--color-bg-card` | `26 26 46` | `#ffffff` | `#ffffff` |
| `--color-bg-hover` | `35 35 66` | `233 238 246` | `253 230 240` |
| `--color-bg-border` | `42 42 68` | `220 227 238` | `251 207 232` |
| `--color-accent` | `233 69 96` | `225 29 72` | `236 72 153` |
| `--color-text-main` | `#ffffff` | `#0f172a` | `41182c` |
| `--color-text-muted` | `#8b8baa` | `#64748b` | `#a25a80` |

`:root, html[data-theme="dark"]` 同时承担默认值;light/sakura 额外设 `color-scheme: light`。

### 10.2 Tailwind 映射

```js
colors: {
  bg: { DEFAULT: 'rgb(var(--color-bg) / <alpha-value>)',
        deep / card / hover / border ... },
  accent: { DEFAULT / light / dark },
  muted:  'rgb(var(--color-text-muted) / <alpha-value>)',
  white:  'rgb(var(--color-text-main) / <alpha-value>)',  // 注意:主题主文字色
  'pure-white': '#ffffff',
  'pure-black': '#000000',
}
```

> ⚠️ `text-white` 实际映射到**主题主文字色**,在浅色主题下为深色文字。需要真正纯白时使用 `text-pure-white`。

组件类(`@layer components`):`.btn` / `.btn-primary` / `.btn-ghost` / `.btn-outline` / `.input` / `.card` / `.label`,以及 `.ellipsis-1` / `.ellipsis-2` 截断工具类。

### 10.3 切换机制

三层优先级:`localStorage("dlsite_theme")` 用于首屏防闪烁 → 数据库 `settings.theme` 在挂载后覆盖 → 用户点击即时切换并写库。

## 12. 附录:设计约束与参考

### 12.1 已知约束与设计取舍

| 约束 | 说明与取舍 |
|:---|:---|
| 单 SQLite 连接 + 全局 Mutex | 简单可靠;所有 DB 操作走 `spawn_blocking`,写入串行化,当前数据规模下无瓶颈 |
| 下载「暂停」语义 | 仅改状态与广播,不真正挂起读取循环 —— 实现简单,但暂停期间仍会消耗网络 |
| asmr.one 播放历史 | 官方无公开云端 API,回退为本应用播放记录 |
| asmr.one 分页无总页数 | 按 `hasNext` 逐页加载,符合官方交互 |
| 榜单并列名次 | 以抓取序号为主键,`rank` 仅展示(有回归测试) |
| 在线音轨不写播放进度 | 避免与本地 `track_id` 语义混淆 |
| `text-white` 为主题文字色 | 浅色主题下为深色;需纯白用 `text-pure-white` |
| 悬浮歌词 | 浏览器无法置顶无边框,`window.open` 弹窗 + BroadcastChannel 替代 |
| 代理仅 HTTP(S) | `reqwest` 不读取系统代理设置;VPN TUN 模式无需配置 |
