# 🎧 ASMR DB v2.1.0

一个轻量、美观的 **DLsite 作品管理 Web 应用**，聚焦 **ASMR 音声作品** 的管理与播放，同时支持同人游戏、漫画等作品类型。纯浏览器访问，Rust 驱动后端。

基于 [设计书.md](设计书.md) 迭代升级。v3.0 起从 Tauri 桌面端改造为 **Rust (axum) + Vue 3** 的 B/S 架构。

---

## ✨ 核心功能

| 模块 | 说明 |
|:---|:------|
| 🗂️ **作品库** | 网格 / 列表视图切换、FTS5 全文毫秒级搜索、已下载/未下载状态筛选、作品分组（Group）、标签筛选、多字段排序、分页 |
| ➕ **导入作品** | 输入 RJ 号自动抓取元数据（封面/多语言标题/社团/声优/标签/简介）；**智能双数据源**：优先 DLsite 官方，受阻自动无缝回退 asmr.one；**导入时可选一键关联本地文件夹并智能匹配分组**；本地文件夹递归扫描智能识别 RJ 号 |
| 📄 **作品详情** | 多语言标题展示、元数据与声优信息、自定义标签编辑与着色、音轨列表、一键复制 RJ 号、官方页面一键跳转、**一键关联本地文件夹并自动划分分组** |
| ⬇️ **下载引擎** | 下载队列管理、HTTP Range 断点续传、实时下载进度与速率监控（SSE 推送）、暂停/继续/取消、下载后自动解压 `.zip` 并自动扫描提取音轨；**支持 asmr.one 完整文件树自定义勾选下载**（音频/字幕/图片快速筛选） |
| 🎵 **音频播放器** | 播放/暂停/切歌、进度条拖拽 Seek（HTTP Range 流式传输）、0.5x~2.0x 倍速播放、循环模式（单曲/列表/不循环）、播放进度持久化记忆、常驻迷你控制栏 |
| 💬 **智能字幕系统** | 支持 `.vtt` / `.srt` / `.lrc` 字幕解析；**asmr.one 在线试听时自动抓取字幕并优先匹配中文字幕**；支持**浏览器悬浮歌词小窗口**（弹窗，与主窗口实时同步） |
| 🌐 **asmr.one 在线试听** | 服务端内置代理注入鉴权流式播放（Token 不暴露给前端），无需下载即可在线畅听并同步显示歌词字幕 |
| 💾 **便携数据库与数据迁移** | SQLite 数据库直接存放在服务端程序同级目录（`dlsite_manager.db`）；设置页支持 **`VACUUM INTO` 一键导出备份（浏览器下载）** 与**上传 .db 文件安全还原** |
| 🎨 **三套个性化主题** | 包含 **深色模式 (Midnight Obsidian)**、**浅色明亮 (Clean Slate)** 与 **樱花粉系 (Sakura Pink)**，实时一键切换 |
| ⚙️ **设置面板** | 三套主题风格切换、下载目录（服务端目录浏览器）、asmr.one Token 配置、数据库备份/还原与目录一键定位 |

## 🛠️ 技术栈

- **后端**: Rust + [axum](https://github.com/tokio-rs/axum)（HTTP API / SSE 事件 / 音频 Range 流 / asmr.one 代理）
- **前端**: Vue 3 + TypeScript + Vite + Tailwind CSS + Pinia + Lucide Icons
- **数据库**: SQLite (`rusqlite`, WAL 模式 + FTS5 独立全文索引)
- **网络/下载**: `reqwest` (Rust, 支持 Range 分块与流式请求)
- **音频引擎**: Howler.js (HTML5 Audio, 支持 Range seek)

## 🚀 运行与构建

### 前置要求

| 工具 | 版本 | 说明 |
|:---|:---|:------|
| [Rust](https://rustup.rs/) | 1.75+ | 服务端编译 |
| [Node.js](https://nodejs.org/) | 18+ | 含 npm |

### 本地开发模式

```bash
npm install          # 安装前端依赖
npm run dev          # 同时启动前端 (Vite :1420) 与 Rust 服务端 (:1421)
```

浏览器打开 http://localhost:1420 即可使用（Vite 会把 `/api` 代理到 Rust 服务端）。

### 生产模式

```bash
npm run start        # 构建前端 dist + 以 release 模式启动 Rust 服务端
# 或分步执行：
npm run build        # 构建前端到 dist/
cargo run --release --manifest-path server/Cargo.toml
```

服务端默认在 `http://127.0.0.1:1421` 上同时提供 API 与前端静态资源（`dist/`）。

### 环境变量

| 变量 | 默认 | 说明 |
|:---|:---|:------|
| `ASMR_PORT` | `1421` | 服务端监听端口 |
| `ASMR_HOST` | `127.0.0.1` | 监听地址（设为 `0.0.0.0` 可局域网访问） |
| `ASMR_DB_DIR` | exe 同级目录 | SQLite 数据库存放目录 |
| `ASMR_DIST_DIR` | 自动探测 | 前端构建产物目录 |

## 📝 使用指南

### 1. 导入作品
* **RJ 号导入**：在侧边栏点击 **导入作品**，输入 RJ 号（例如 `RJ01014447`），选择数据源预览元数据并导入。
* **本地文件夹扫描**：通过内置的**服务端目录浏览器**选择存放 ASMR 文件夹的根目录，程序将自动递归扫描并识别 RJ 号，同时可将分类文件夹智能设为作品分组（Smart Group）。

### 2. asmr.one 在线试听与字幕
* 在「设置 → asmr.one 数据源」中按说明从浏览器复制并粘贴 Token（JWT）。
* 在作品详情页点击 **asmr.one 在线试听**，系统会自动检索该作品的在线音轨并**自动抓取匹配的 `.vtt` / `.srt` / `.lrc` 字幕**。
* 进入播放页即可边听边看字幕，点击字幕栏按钮可打开**悬浮歌词窗口**（浏览器弹窗）。

### 3. 本地播放与音轨管理
* 在作品详情页点击 **扫描音轨** 或 **播放**，即可加载本地音频（服务端以 HTTP Range 流式传输，支持拖动快进）。
* 支持快捷键：
  - `Space`：播放 / 暂停
  - `←` / `→`：快退 / 快进 5 秒
  - `↑` / `↓`：音量微调

## 📂 数据存储说明

* 数据库文件 `dlsite_manager.db`（及其 WAL 索引）默认直接保存在 **服务端可执行文件所在的同一目录下**（开发模式可用 `ASMR_DB_DIR` 指定）。
* **数据迁移/备份**：复制该文件（若存在 `-wal` 和 `-shm` 一并复制）即可完整迁移；或在设置页使用导出/导入功能。
